\doxysubsection{Detailed Description}
The parser is the file that transform a list of tokens into a ast The parser is based of the very common gradient descent iteration (It was the simplest and most common so I chose that) It uses \doxylink{classCompilerPipeline}{Compiler\+Pipeline} for adding modules and making treating multiple files in multiple threads speeding up the process. 

With time these concept and this parser will be expanded to contain more features and fixes.
