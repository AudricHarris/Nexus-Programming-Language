Detailed Description

physical token

It contains a few attributes to extract kind of token, word it contains, the line it is at. It also contains a method allowing to extract name from TokenKind

@attributes kind : The token kind it is @attributes word : physical word that the token is @attributes line : the line the token is at (usefull for debugging) @attributes column : the column the token is at (usefull for debugging)

@method getKind : returns the token Kind @method getWord : returns the word @method getLine : returns the line @method getColumn : returns the column @method toString : returns a string format of token Kind (mostly visual)
